# Matriz de Rastreabilidade de Requisitos — EventIF

Este documento relaciona cada requisito oficial (`docs/especificacao_oficial.pdf`) aos componentes técnicos e testes responsáveis.

**Legenda de Status:**
- `PENDENTE`: ainda não implementado.
- `EM_ANDAMENTO`: implementação iniciada, aguardando testes ou revisão.
- `IMPLEMENTADO`: código pronto, aguardando validação completa na auditoria.
- `PASSOU`: implementado, testado e verificado com evidência concreta.
- `PARCIAL` / `FALHOU`: lacuna ou falha identificada.

> **Regra:** nenhum item deve ser marcado como `IMPLEMENTADO` ou `PASSOU` sem classe, rota, template ou teste realmente existente e verificado.
